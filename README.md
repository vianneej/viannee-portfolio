# Viannee Portfolio Website

A personal portfolio website built to showcase Viannee's projects, experience, resume, and a little bit about her.

## Deploy

This website can be hosted for free using [Vercel](https://vercel.com).

1. Push the project to GitHub.
2. Import the repository into Vercel.
3. Select **Other** as the framework.
4. Click **Deploy**.

## Customize

Most of the portfolio can be updated by changing the files in the `assets` folder and editing `index.html` or `script.js`.

- **Profile Photo:** `assets/profile.jpg`
- **Resume:** `assets/Viannee_J_Rosa-Arroyo_Resume.pdf`
- **Project Links:** Update them in `index.html`
- **Photos:** Add images to `assets/` and update the `lifePhotos` list in `script.js`
- **Socials & Contact Info:** Replace the placeholder links in `index.html`
